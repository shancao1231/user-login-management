# 环境变量

## 快速开始

```bash
cp .env.example .env
# 编辑 .env：至少设置 DATABASE_URL、SESSION_SECRET
pnpm db:up
pnpm dev
```

`.env` 已被 `.gitignore` 忽略；**只提交** `.env.example` 作为模板。

## 变量一览

| 变量                      | 必填     | 阶段 | 说明                                      |
| ------------------------- | -------- | ---- | ----------------------------------------- |
| `DATABASE_URL`            | 是       | 0.4  | Prisma 连接串，见 `docs/本地数据库.md`    |
| `SESSION_SECRET`          | 是       | 2    | HMAC/签名用，≥32 字符随机串               |
| `APP_URL`                 | 生产建议 | 2/4  | 站点根 URL；Cookie、重置邮件链接          |
| `SESSION_COOKIE_NAME`     | 否       | 2    | 默认 `session`                            |
| `SESSION_MAX_AGE_SECONDS` | 否       | 2    | 会话时长，默认 7 天                       |
| `RESEND_API_KEY`          | 否       | 4    | 配置后走 Resend；未配置则控制台 `[mail:dev]` |
| `MAIL_FROM`               | 否       | 4    | 发件人，如 `noreply@yourdomain.com`       |
| `REDIS_URL`               | 否       | 6    | 配置后全局限流走 Redis；未配置用内存      |
| `LOG_LEVEL`               | 否       | 5    | pino 级别，默认生产 `info`                |
| `SENTRY_DSN`              | 否       | 5    | 异常监控                                  |

## 生成 SESSION_SECRET

```bash
openssl rand -base64 32
```

## 服务端校验

启动前可通过 `lib/env.ts` 的 `getServerEnv()` 校验必填项（第 2 阶段 API 将统一使用）。

## 安全注意

- 勿把 `.env`、真实密码、token 写入仓库或审计日志。
- 生产使用托管平台的「环境变量」配置，与本文件模板字段一一对应即可。
