# 第 3 阶段验收

## API

```bash
pnpm dev
pnpm smoke:3
```

## 浏览器（管理员登录后）

1. `/admin` — 概览统计
2. `/admin/users` — 搜索、状态筛选、分页
3. 进入用户详情 — 改姓名、禁用/启用、分配角色、管理员重置密码
4. 用普通用户访问 `/admin` — **403**（无 `user:read` 等权限）

## 安全规则

- 不能禁用自己
- 不能禁用/降职**最后一个** `super_admin`
- 禁用或重置密码后 **撤销该用户全部 Session**（重新 `pnpm smoke:2` 用被禁用账号应无法 `/me`）
