# 第 6 阶段验收

## 前置

```bash
pnpm db:up
pnpm db:migrate   # 含 EmailVerificationToken
pnpm db:seed
# 可选 Redis 限流：REDIS_URL=redis://127.0.0.1:16379
pnpm dev
```

## 功能清单

| ID  | 功能 | 验收方式 |
| --- | ---- | -------- |
| 6.1 | 用户软删 / 恢复 | 用户详情 → 软删除 → 列表开「含软删」→ 恢复 |
| 6.2 | 会话管理 | `/admin/sessions` 列表 + 撤销一条 |
| 6.3 | Redis 限流 | 配置 `REDIS_URL` 后登录限流仍生效（无 Redis 则内存） |
| 6.4 | 角色权限只读 | `/admin/roles`（需 `role:manage`） |
| 6.5 | 邮箱验证 | 注册后日志出验证链接；`/profile` 可重发 |
| 6.6 | MFA | ⏳ 未实现 |
| 6.7 | OAuth | ⏳ 未实现 |
| 6.8 | 权限在线编辑 | ⏳ 未实现（当前只读） |

## 与「禁用」区别

- **禁用**：`status=DISABLED`，列表仍见，可启用  
- **软删**：`deletedAt` 有值，默认列表隐藏，撤销全部 Session，可恢复
