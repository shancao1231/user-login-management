## 自动化（本机 / CI）

| 项              | 命令 / 条件                                                                        | 结果                  |
| --------------- | ---------------------------------------------------------------------------------- | --------------------- |
| 代码质量        | `pnpm check`                                                                       | ✅                    |
| 生产构建        | `pnpm build`                                                                       | ✅（见 0.8 本地复现） |
