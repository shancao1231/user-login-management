## MVP 边界（已确认）

**本版本包含：**

- 邮箱 + 密码注册/登录/登出
- 服务端 Session（HttpOnly Cookie + DB 存 token 哈希）
- RBAC：`super_admin` / `admin` / `user`
- 管理端：用户列表（分页/搜索/状态）、禁用启用、分配角色、管理员重置密码
- 审计日志（关键操作）
- 忘记密码 / 重置密码（第 4 阶段）

**本版本暂不包含：**

- 邮箱验证、MFA、第三方登录
- 复杂权限编辑器、组织架构
- Redis 限流（MVP 可用内存/简单限流，后续升级）

**技术栈（方案 A）：**

- Next.js App Router + TypeScript
- UI：Ant Design + Tailwind
- PostgreSQL + Prisma + Zod
- Session 自建 + argon2/bcrypt
- 测试：Vitest + Playwright（第 5 阶段）
- 部署：Vercel + Neon/Supabase 或 Docker（第 5 阶段）
