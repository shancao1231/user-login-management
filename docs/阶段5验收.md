# 第 5 阶段验收

## 5.1 Vitest

```bash
pnpm test:unit
```

覆盖：密码 argon2、权限纯函数、Session token 哈希、限流、Cookie 选项、Zod 校验。

## 5.2 Playwright

前提：`pnpm db:up`、`pnpm db:migrate`（已迁移可跳过）、`pnpm db:seed`。

```bash
pnpm exec playwright install chromium   # 首次
pnpm test:e2e
```

或已有 `pnpm dev` 时：

```bash
PLAYWRIGHT_BASE_URL=http://127.0.0.1:3000 pnpm test:e2e
```

验收：

1. 管理员登录 → `/admin/users` 可见种子邮箱
2. 新注册用户访问 `/admin` → 403
