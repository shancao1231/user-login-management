pnpm dev   # 大改路由后建议重启 dev

## 忘记密码（开发环境）

1. 打开 `/forgot-password`，填写已注册邮箱
2. 终端应出现 `[mail:dev]` 及完整重置链接
3. 打开链接 `/reset-password?token=...`，设置新密码 → 跳转登录

生产：配置 `RESEND_API_KEY` + `MAIL_FROM` + `APP_URL`。

## 审计日志

管理员登录 → `/admin/audit-logs`：分页、按动作/关键词筛选。

应能看到 `auth.login`、`auth.forgot_password`、`user.disable` 等记录。
