# 本地 PostgreSQL（Docker）

## 端口说明

本机 **5432、5433…** 已被其他服务占用，本项目容器映射到宿主机 **15432**：

| 项          | 值                         |
| ----------- | -------------------------- |
| 容器名      | `user-login-admin-db`      |
| 宿主机端口  | `15432`                    |
| 库名        | `user_login_admin`         |
| 用户 / 密码 | `app` / `app_dev_password` |

连接串（与 `.env.example` 一致）：

```text
postgresql://app:app_dev_password@localhost:15432/user_login_admin?schema=public
```

## Redis（第 6 阶段，可选）

`docker compose` 同时提供 Redis，映射 **16379**：

```text
REDIS_URL="redis://127.0.0.1:16379"
```

未配置 `REDIS_URL` 时限流仍使用进程内内存（单实例开发足够）。

## 常用命令

```bash
pnpm db:up      # 启动 Postgres + Redis
pnpm db:down    # 停止并移除容器（卷保留）
pnpm db:logs    # 查看日志
pnpm db:generate # 生成 Prisma Client
pnpm db:studio  # 图形化查看（第 1 阶段有表后更有用）
```

## 连通性验收

1. 容器健康：`docker compose ps` 显示 `healthy`
2. CLI：`pnpm exec prisma db execute --stdin <<< "SELECT 1"`
3. API：先 `pnpm dev`，访问 http://localhost:3000/api/health/db ，应返回 `{"ok":true,"database":"connected"}`
