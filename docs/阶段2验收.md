# 第 2 阶段验收

## API 自动化

```bash
pnpm dev   # 需重启 dev 以加载新路由
pnpm smoke:2
```

预期：`smoke:phase2 OK`，且登出后 `/api/auth/me` 返回 401。

## 浏览器手工

1. http://localhost:3000/register — 注册普通用户 → 跳转 `/profile`
2. 登出后 `/login` — 使用 seed 管理员 `admin@example.com` / `ChangeMe_Admin123!`
3. 首页显示已登录，可进入 **管理后台**（管理员）或仅 **个人资料**（普通用户）
4. 普通用户访问 `/admin` → 页面 **403**
5. 未登录访问 `/profile` → 跳转 `/login?next=/profile`

## 已实现能力

- Session：随机 token + SHA-256 入库，`HttpOnly` Cookie
- `/api/auth/register|login|logout|me`
- 登录/注册内存限流（IP + 邮箱）
- `middleware`：`/admin`、`/profile` 无 Cookie 跳登录
- 审计：`auth.register` / `auth.login` / `auth.logout`
