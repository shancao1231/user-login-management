# 种子数据（第 1 阶段）

## 运行

```bash
pnpm db:up
pnpm db:migrate   # 已有迁移则跳过
pnpm db:seed
```

## 默认超级管理员

| 项   | 值                                                      |
| ---- | ------------------------------------------------------- |
| 邮箱 | `admin@example.com`（可用 `SEED_ADMIN_EMAIL` 覆盖）     |
| 密码 | `ChangeMe_Admin123!`（可用 `SEED_ADMIN_PASSWORD` 覆盖） |
| 角色 | `super_admin`                                           |

**登录 API 在第 2 阶段实现**；当前仅保证数据库内账号存在。

## 权限与角色

| 权限 code     | 说明     |
| ------------- | -------- |
| `user:read`   | 查看用户 |
| `user:write`  | 管理用户 |
| `role:manage` | 管理角色 |
| `audit:read`  | 查看审计 |

| 角色 code     | 权限                              |
| ------------- | --------------------------------- |
| `super_admin` | 全部                              |
| `admin`       | user:read, user:write, audit:read |
| `user`        | 无（普通注册用户默认角色）        |

## 自定义 seed 环境变量（可选）

```bash
SEED_ADMIN_EMAIL="you@example.com"
SEED_ADMIN_PASSWORD="your-secure-password"
SEED_ADMIN_NAME="管理员"
pnpm db:seed
```

重复执行 seed 会 **upsert** 权限/角色，并更新管理员密码哈希（若改了 `SEED_ADMIN_PASSWORD`）。
