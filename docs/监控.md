# 日志与监控（第 5 阶段）

## 结构化日志（pino）

实现：`lib/log.ts`

- 开发默认 `debug`，生产默认 `info`
- 可通过 `LOG_LEVEL` 覆盖
- 敏感字段名在 `redact` 列表中（`password`、`token` 等）

开发环境未配置 Resend 时，找回密码邮件通过 `log.info` 输出（字段 `mailDev: true`），可在本地终端查看重置链接。

## Sentry（可选）

1. 在 Sentry 创建 Next.js 项目，复制 **DSN**
2. 生产环境设置 `SENTRY_DSN`
3. 安装官方 SDK：

```bash
pnpm add @sentry/nextjs
npx @sentry/wizard@latest -i nextjs
```

4. 删除或替换根目录 `instrumentation.ts` 中的占位提示

当前仓库**未默认安装** `@sentry/nextjs`，以控制依赖体积；仅保留 `instrumentation.ts` 占位与环境变量说明。
